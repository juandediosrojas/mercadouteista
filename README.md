
  # Interfaz e-commerce universitaria

  This is a code bundle for Interfaz e-commerce universitaria. The original project is available at https://www.figma.com/design/mCxnv7Io5CwXjQ5gg5WgCl/Interfaz-e-commerce-universitaria.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Desplegar en firebase hosting

  1. Instala Firebase CLI: `npm install -g firebase-tools`.
  2. Inicia sesión: `firebase login`.
  3. Configura Firebase Hosting: `firebase init hosting`.
  4. Genera la aplicación: `npm run build`.
  5. Despliega: `firebase deploy --only hosting`.
